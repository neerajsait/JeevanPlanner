# JeevanPlanner

> A browser-based financial-planning toolkit with pages for students, freshers, and detailed planning.

## Overview

Despite the repository name, the current HTML pages focus on personal finance: take-home pay, expenses, loans, savings, investments, and longer-term planning. The pages are static and calculate in the browser.

## What’s in this repo

- Student money-planning page
- Fresher salary and monthly-budget reality check
- Pro planner for income, expenses, SIPs, loans, asset allocation, and retirement

## Stack

HTML, CSS, and client-side JavaScript; Tailwind CSS and browser-loaded assets are used by the pages.

## Getting started

1. Clone the repository and open `JeevanPlanner-main/student.html`, `fresher.html`, or `pro.html` in a modern browser.
2. No backend service or package-install step is present in the current project layout.

## Notes

The planner includes financial estimates, not personalized financial advice. Tax assumptions are tied to FY 2025–26 and will need updating as rules change.
